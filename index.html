04 / مراجعة كود السيرفر المصدري

مقارنة الكود المصاب بالكود المصحح

اختبار أنماط الكود المصدري التوضيحية — قارن بين الشفرة المصابة بالأحمر والشفرة المصححة بالأخضر لثغرات الـ IDOR والـ AuthZ والـ Races.

❌ VULNERABLE LOGIC (UNAUTHORIZED ACCESS) app.get('/api/v1/invoices/:id', async (req, res) => {
  const invoiceId = req.params.id;
  // MISSING: Ownership verification of invoiceId against req.user.id
  const invoice = await Invoice.findById(invoiceId);
  return res.json(invoice);
});
🟢 REMEDIATED LOGIC (SECURE AUTHZ) app.get('/api/v1/invoices/:id', async (req, res) => {
  const invoiceId = req.params.id;
  // SECURE: Verify object ownership against authenticated session
  const invoice = await Invoice.findOne({ _id: invoiceId, userId: req.user.id });
  if (!invoice) return res.status(403).json({ error: "Access Denied" });
  return res.json(invoice);
});

05.5 / هل الكامب مناسب ليك؟

مش كل حد محتاج يدخل الكامب — وده مقصود

أقوى دفعة مش هي الأكبر عددًا؛ هي الدفعة اللي داخلة مستعدة تطبق، تفكر، تسأل، تجرب، تغلط، تراجع، وتكمل.

الكامب مناسب ليك لو...

  • فاهم أساسيات Linux والويب، لكن أول ما تدخل Target حقيقي بتحس إنك مش عارف تبدأ منين.
  • بتتنقل بين Tools وPayloads كتير من غير Methodology ثابتة تعرف تمشي عليها.
  • عاوز Feedback مباشر على طريقة تفكيرك، مش بس حد يقولك الـPayload اشتغل أو لأ.
  • مستعد تعمل واجبات، تراجع غلطاتك، وتلتزم بالـHunting والتطبيق بين السيشنات.
  • هدفك تبقى Hunter مستقل يعرف يبني Workflow ويطوره، مش يفضل محتاج خطوات محفوظة.

متدخلش الكامب لو...

  • مستني Payload سحري أو طريقة ثغرة واحدة تحفظها وتكررها في كل مكان.
  • داخل على أساس إن في باونتي مضمونة خلال الكامب.
  • مش ناوي تطبق أو تعمل واجبات خارج وقت السيشن.
  • كل تركيزك تجمع Tools أكتر بدل ما تفهم إمتى وليه تستخدم كل أداة.
  • مستني حد يعمل مكانك التفكير الصعب والاستمرار اللي المجال محتاجه.
نصيحة صغيرة قبل ما تقدّم

مش هوعدك إنك أكيد هتجيب باونتي خلال الكامب — لو ده اللي بتدور عليه، متدخلش.

المجال فيه مغالطات وتسويق كتير، فخلّي الصورة واضحة من البداية: ممكن ثغرة IDOR بسيطة في بعض البرامج تتكافأ بـ 300–400 دولار أو أكتر حسب البرنامج والخطورة والأثر، وممكن تقرير تاني يبقى Duplicate أو من غير مكافأة — مفيش رقم مضمون. هدفي إن تفكيرك يبقى صح من الأساس، وتعرف تبني Methodology بنفسك، وتطلع فرضيات أحسن، وتفهم السيستم بعمق؛ عشان تبدع وتفكر وتبتكر بدل ما تحفظ طريقة وتكررها. اجتهادك واستمرارك وجودة تطبيقك هما اللي يحولوا الأساس ده لنتائج مع الوقت.

وبقولك الكلام ده لأني مريت بنفسي بمرحلة التوهان دي. فضلت فترة طويلة أنط بين كورسات ومصادر قبل ما أفهم الطريق. مش هدفي أبيعلك Shortcut مش موجود؛ هدفي أوضحلك الطريق الحقيقي وأساعدك تمشيه من البداية بتفكير أرتب وأصح.

إجابات مباشرة قبل ما تقدّم

دي أهم الأسئلة اللي غالبًا بتكون في دماغك قبل ما تقدّم، وإجاباتي عليها بشكل مباشر.

لأ، مش محتاج تكون Senior Developer. هنبدأ من أساسيات الـWeb وHTTP اللي محتاجها فعلًا، وبعدها نبني واحدة واحدة على Requests وAPIs وAccess Control وAuthentication وLogic Testing. لو عندك أساسيات Linux وWeb بسيطة هتخلي التجربة أسهل عليك.
سعر الدفعة الأولى 4,000 ج.م بعد خصم إطلاق 33% من السعر الأصلي 6,000 ج.م. السعر شامل 12 سيشن، التسجيلات، انترفيو قبل القبول، متابعة فردية 1:1، الواجبات والمتابعة اليومية. الدفع متاح عن طريق Vodafone Cash أو InstaPay أو تحويل بنكي بعد الانترفيو والقبول.
أيوه. أنا بهانت بشكل نشط من مارس 2023 على HackerOne وYesWeHack وبرامج خاصة، ولسه بهانت وأنا بقدّم الكامب. وده مهم بالنسبة لي لأن اللي بشرحه يفضل مرتبط بطريقة الشغل الحقيقية على Targets، مش يتحول لنظرية متكررة.
كل السيشنات اللايف بتتسجل HD وبتتوفر للطلاب. تقدر ترجع للتسجيل، وبعدها تستخدم المتابعة اليومية وتسألني في أي نقطة فاتتك علشان متفضلش واقف مكانك.
لأ — وأنا أفضل أقولك ده بوضوح قبل ما تدفع. أقدر أساعدك تبني الأساس، الـMethodology، التحليل وطريقة التدريب؛ لكن مقدرش أضمن إن برنامج هيقبل Report أو يدفع Bounty. استمرارك وجودة شغلك هما اللي يحولوا الأساس ده لنتائج مع الوقت.
