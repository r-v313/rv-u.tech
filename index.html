04 / مراجعة كود السيرفر المصدري

مقارنة الكود المصاب بالكود المصحح

اختبار أنماط الكود المصدري التوضيحية — قارن بين الشفرة المصابة بالأحمر والشفرة المصححة بالأخضر لثغرات الـ IDOR والـ AuthZ والـ Races.

❌ VULNERABLE LOGIC (UNAUTHORIZED ACCESS) app.get('/api/v1/invoices/:id', async (req, res) => {
  const invoiceId = req.params.id;
  // MISSING: Ownership verification of invoiceId against req.user.id
  const invoice = await Invoice.findById(invoiceId);
  return res.json(invoice);
});
🟢 REMEDIATED LOGIC (SECURE AUTHZ) app.get('/api/v1/invoices/:id', async (req, res) => {
  const invoiceId = req.params.id;
  // SECURE: Verify object ownership against authenticated session
  const invoice = await Invoice.findOne({ _id: invoiceId, userId: req.user.id });
  if (!invoice) return res.status(403).json({ error: "Access Denied" });
  return res.json(invoice);
});

🌟 6 أسابيع · 12 محاضرة

06 / منهج الـ 12 محاضرة لايف

منهج عملي مكثف على مدار 6 أسابيع

6 أسابيع، 12 سيشن لايف — اتبنت خصيصاً للمبتدئين والمتوسطين اللي عاوزين خطة عمل حقيقية يمشوا عليها (مع تسجيل جميع الجلسات كاملة).

Week 01 · S01

Intro & Environment Setup

نتعارف مع بعض، ناخد الأساسيات، ونجهز الأدوات (Burp، البروكسي، الشهادات) لايف.

Week 01 · S02

Web Fundamentals

إزاي الويب شغال فعلياً، ودورة الطلب كاملة، وأول نظرة على شكل الـ JWT.

Week 02 · S03

Recon

Subdomains وتحليل الـ JS واكتشاف الـ parameters والتجاوز عملياً.

Week 02 · S04

Access Control, Sessions & JWT Attacks

IDOR وBOLA وإدارة الجلسات وجميع طرق هجوم الـ JWT.

Week 03 · S05

Business Logic & Race Conditions

استغلال سير العمل والتلاعب بالحالة والسباق الزمني للطلبات بـ Turbo Intruder.

Week 03 · S06

Cache Poisoning & Account Takeover

هجمات الكاش وثغرات استعادة الباسورد وتجاوز الـ 2FA واستغلال OAuth.

Week 04 · S07

API Security

نظرة سريعة على SOAP، وبعدها غوص كامل في GraphQL introspection وbatching وتجاوز الصلاحيات المتداخل.

Week 04 · S08

Methodology

تبني منهجية صيد كاملة وتجربها بإيدك على طلبات حقيقية.

Week 05 · S09

AI for Bug Bounty

استخدام الـ AI في الاستطلاع وبناء الفرضيات ومساعدك الشخصي في الصيد.

Week 05 · S10

Automation & Scripting Mindset

تتعلم التفكير في بناء الأتمتة وكتابة سكريبتاتك بنفسك وتجربة أدواتي الشخصية لايف.

Week 06 · S11

Live Hunting

برنامج حقيقي وفريق حقيقي وهدف حقيقي — بتطبق كل حاجة اتعلمتها لايف.

Week 06 · S12

Reporting & Presentations

تكتب تقرير يتقبل ويتدفع عليه باونتي، وبعدين تعرض نتائج فريقك.
