هل الكامب مناسب ليك؟

مناسب ليك لو

  • عندك أساسيات Linux والويب وWeb Security.
  • بتتوه لما تدخل Target حقيقي ومحتاج Methodology.
  • مستعد تطبق بين السيشنات وتاخد Feedback.

مش مناسب ليك لو

  • بتدور على Payloads محفوظة أو طريقة سحرية.
  • داخل متوقع Bounty مضمونة أو نتيجة مالية سريعة.
CURRICULUM

المنهج في 6 أسابيع

الهدف النهائي: تخرج بـMethodology عملية تقدر تدخل بيها Target وتقرر تعمل إيه وليه.

SESSION 01

تطوير عقليتك

تفهم الـTarget والـFeatures والـTrust والـAssumptions وتطلع Tests من فهمك للـFlow بدل التجربة العشوائية.

SESSION 02

افهم أي Request قدامك

نفك الـRequest والـResponse والـHeaders والـCookies والـParameters والـSession والـJWT ونربطهم بالهوية والصلاحيات.

SESSION 03

حوّل الـTarget لخريطة واضحة

Recon بهدف واضح وترتيب الـSubdomains والـURLs والـJavaScript والـParameters والـLeaks والـFuzzing حسب الأولوية.

SESSION 04

افهم الصلاحيات قبل IDOR

نفهم الـUser والـObject والـRole والصلاحية المتوقعة ونطبق على IDOR وBOLA والصلاحيات الأفقية والرأسية.

SESSION 05

Business Logic وRace Conditions

نرسم الـWorkflow والحالات والافتراضات ونطلع Abuse Cases وRace Tests منطقية.

SESSION 06

اختبر رحلة الحساب كاملة

نربط Login وPassword Reset و2FA وOAuth والـSessions والـCache behavior كمنظومة واحدة.

SESSION 07

اختبر الـAPIs بشكل منظم

REST وGraphQL والـSchemas والـEndpoints والـParameters مع تحديد حدود الصلاحيات والبيانات الحساسة.

SESSION 08

ابنِ الـMethodology اللي هتشتغل بيها

نحوّل الـScope والـRecon والـPrioritization والـManual Testing والملاحظات لـWorkflow مكتوبة قابلة للتعديل.

SESSION 09

AI for Bug Bounty

استخدام AI في فهم Code وJavaScript وترتيب Recon والملاحظات وتوليد فرضيات مع Privacy وOPSEC وValidation.

SESSION 10

Automation للحاجات اللي بتضيع وقتك

نحدد الـBottlenecks الحقيقية ونربط Tools وScripts صغيرة ونتعامل مع Inputs وOutputs والNoise والأخطاء.

SESSION 11

Live Hunting مباشر

هانت مباشر على Target حقيقي داخل Scope مصرح به مع شرح القرارات والـDead Ends وطريقة الربط بين الـsignals.

SESSION 12

Final Team Review

كل فريق يعرض اختبر إيه وفكر إزاي وإيه اللي استبعده ووصل لإيه وناخد Feedback على الرحلة كاملة.

FAQ

أهم 4 أسئلة

محتاج أساسيات Linux والويب وتكون ذاكرت جزء من Web Security. مش لازم تكون جبت Bug أو Bounty قبل كده؛ الانترفيو هو اللي هيحدد هل مستواك مناسب للدفعة الحالية.

سعر أول دفعة أونلاين 4000 جنيه. الدفع بعد الانترفيو والقبول فقط لو قررت تدخل، والقبول لوحده مش بيلزمك تدفع.

السيشنات بتتسجل للدفعة. لو فاتتك Session تراجع التسجيل وبعدها تستخدم المتابعة والـ1:1 عشان نفك أي نقطة وقفت معاك.

لأ. دوري أبني معاك الأساس والـMethodology والتحليل وطريقة التدريب، لكن مفيش حد يقدر يضمن إن Program هيقبل Report أو يدفع Bounty.
