05 / هل الكامب مناسب ليك؟

مش كل حد محتاج يدخل الكامب — وده مقصود

أقوى دفعة مش هي الأكبر عددًا؛ هي الدفعة اللي داخلة مستعدة تطبق، تفكر، تسأل، تجرب، تغلط، تراجع، وتكمل.

الكامب مناسب ليك لو...

  • فاهم أساسيات Linux والويب، لكن أول ما تدخل Target حقيقي بتحس إنك مش عارف تبدأ منين.
  • بتتنقل بين Tools وPayloads كتير من غير Methodology ثابتة تعرف تمشي عليها.
  • عاوز Feedback مباشر على طريقة تفكيرك، مش بس حد يقولك الـPayload اشتغل أو لأ.
  • مستعد تعمل واجبات، تراجع غلطاتك، وتلتزم بالـHunting والتطبيق بين السيشنات.
  • هدفك تبقى Hunter مستقل يعرف يبني Workflow ويطوره، مش يفضل محتاج خطوات محفوظة.

متدخلش الكامب لو...

  • مستني Payload سحري أو طريقة ثغرة واحدة تحفظها وتكررها في كل مكان.
  • داخل عشان Bounty مضمونة أو فلوس سريعة.
  • مش ناوي تطبق أو تعمل واجبات خارج وقت السيشن.
  • كل تركيزك تجمع Tools أكتر بدل ما تفهم إمتى وليه تستخدم كل أداة.
  • مستني حد يعمل مكانك التفكير الصعب والاستمرار اللي المجال محتاجه.
06 / 6 أسابيع · 12 سيشن · قدرات واضحة

كل سيشن لها Core واضح وSupporting Topics ونتيجة عملية

الفكرة مش نحشر أسماء ثغرات كتير في ساعتين. كل سيشن لها مهارة أساسية بنتعمق فيها، Supporting Topics تكمل الصورة، وOutcome لازم تقدر تعمله بنفسك.

WEEK 01 · DEVELOP YOUR ENVIRONMENT & READ REQUESTS
Deliverable: A controlled setup + a way to understand any requestتطور بيئة شغلك وتتعلم تقرأ أي Request تقابلك في سياق الـApplication Flow، مش تحفظ شكل Request وخلاص.
SESSION 01

Develop Your Hunting Environment

CORE تطوير Workflow الشغل بحيث الاعتراض والتعديل وإعادة الإرسال والتوثيق يبقوا طبيعيين وسريعين.

SUPPORTING Burp setup · Proxy · Certificates · Browser setup · Notes workflow.

OUTCOMEبيئتك جاهزة وتعرف تمسك Request وتعدلها وتقارن النتائج بثقة.
SESSION 02

Understand Any Request You Meet

CORE تفهم أي Request تقابلك: جاي منين، بيحمل State إزاي، وإيه علاقته بالهوية والصلاحيات.

SUPPORTING Headers · Cookies · Parameters · Sessions · JWT introduction.

OUTCOMEتعرف تميّز إيه User-controlled وإيه Identity/State/Authorization context.
WEEK 02 · MAP & AUTHORIZE
Deliverable: Build an Attack Surface and Authorization Modelتحول Target لخريطة مرتبة، ثم تفهم مين يقدر يعمل إيه على أي Object.
SESSION 03

Turn a Target into an Attack Surface

CORE Recon بهدف الـPrioritization، مش جمع Data بلا نهاية.

SUPPORTING Subdomains · URLs · JavaScript · Parameters · Leaks · Fuzzing.

OUTCOMEتطلع Target Map نظيفة وتعرف إيه يستاهل Manual Testing الأول.
SESSION 04

Model Authorization Before You Test It

CORE Authorization · Object ownership · IDOR/BOLA reasoning.

SUPPORTING AuthN context · Sessions · JWT · Roles · Horizontal/Vertical access.

OUTCOMEتبني Authorization Checklist وRole/Object Matrix بدل تجربة IDs عشوائيًا.
WEEK 03 · ABUSE WORKFLOWS
Deliverable: Convert workflows into attack hypothesesتبدأ تسأل التطبيق مفترض إيه وإزاي ممكن تكسر الافتراض، بدل سؤال “أنهي Payload؟”.
SESSION 05

Read Business Workflows Like an Attacker

CORE Business Logic reasoning والـTrust assumptions.

SUPPORTING State transitions · Abuse cases · Concurrency · Race-condition testing.

OUTCOMEترسم Workflow وتحدد الافتراضات وتطلع منها اختبارات Logic/Race منطقية.
SESSION 06

Test the Complete Account Lifecycle

CORE فهم Authentication/Recovery كـFlow متكامل.

SUPPORTING Login · Password reset · 2FA · OAuth · Cache behavior.

OUTCOMEتختبر Account Flows كنظام مترابط بدل Endpoints منفصلة.
WEEK 04 · API TESTING & YOUR METHODOLOGY
Deliverable: Test an API and build your own Methodologyتفهم الـAPI نفسها أولًا، وبعدها تبني خطوات اختبار تناسب تصميمها وسلوكها.
SESSION 07

Map and Test an Unfamiliar API

CORE API discovery · Authorization model · Systematic testing.

SUPPORTING REST · GraphQL · Schemas · Endpoints · Parameters · Introspection/Batching where relevant.

OUTCOMEتمسك API جديدة، تعمل Mapping، وتحدد نقاط الـAuthorization/Data exposure اللي تستاهل اختبار.
SESSION 08

Write the Methodology You Will Actually Use

CORE تحويل فهمك للـTarget إلى Workflow قابلة للتكرار والتعديل.

SUPPORTING Scope reading · Recon · Prioritization · Manual testing · Notes · Decision points.

OUTCOMEتطلع بـMethodology مكتوبة End-to-End وتعرف إمتى تغيرها بدل ما تمشي عليها بشكل أعمى.
WEEK 05 · AI & AUTOMATION WITH CONTROL
Deliverable: Build an assisted workflow without outsourcing your thinkingتستخدم AI والأتمتة كرافعة، مش كبديل لفهمك وتحليلك.
SESSION 09

Install, Connect and Control an AI Assistant

CORE نجيب AI Assistant عملي، نثبته، ونربطه بالـWorkflow والأدوات اللي بتستخدمها.

SUPPORTING Tool integration · Recon triage · Code/JS understanding · Hypothesis support · Notes · Validation · Privacy/OPSEC · إمتى تستخدمه وإمتى ما تبعتش له بيانات حساسة أو تثق في ناتجه.

OUTCOMEتقدر تدخل AI في شغلك بشكل مسؤول، وتعرف إمتى يسرعك وإمتى لازم توقفه وتعمل Validation بنفسك.
SESSION 10

Automate Bottlenecks, Not Everything

CORE تحديد الشغل المتكرر اللي فعلًا يستاهل Automation.

SUPPORTING Small scripts · Chaining tools · Filtering noise · Inputs/outputs · Failure handling.

OUTCOMEتحدد Bottleneck وتبني له Tool/Workflow صغيرة بدل تجميع Tools من غير سبب.
WEEK 06 · FULL AUTHORIZED HUNT
Deliverable: Run and communicate a complete authorized huntتطبق المنهجية على Target داخل Bug Bounty Program وبالالتزام بالـScope والـProgram Rules.
SESSION 11

Execute Your Methodology on an Authorized Live Target

CORE اتخاذ القرار الحقيقي وسط Scope حقيقي وDead Ends ووقت محدود.

SUPPORTING Prioritization · Hypotheses · Evidence discipline · Program rules · Safe testing.

OUTCOMEتعرف تكمل لما الـTarget الحقيقي ميبقاش شبه Lab، من غير ما تخرج عن الـScope أو تختبر بشكل غير مسؤول.
SESSION 12

Turn the Hunt into a Professional Finding

CORE Reporting والتواصل الفني الواضح.

SUPPORTING Reproducible steps · Evidence · Impact framing · Team presentation · Triage-friendly writing.

OUTCOMEتحول Issue متحققة إلى Report احترافي وتعرض تفكير فريقك من غير تضخيم Impact لم تثبته.
CAPSTONE HUNT · فريقك مسؤول عن الرحلة كاملة

كل فريق يبدأ من Scope مصرح به، يعمل Plan، ينفّذ الاختبارات، يوثق الـEvidence والـDead Ends، وبعدها يقدم اللي وصل له. ولو النتيجة No Valid Finding، ده مش فشل: هتقدم What We Tested + ليه اختبرناه + إيه اللي استبعدناه + إيه اللي اتعلمناه.

11 / أول دفعة أونلاين · التقديم والقرار

التقديم يبدأ بفهم النظام، مش بالدفع

بيني وبينك قبل ما تدفع

أنا مش هبيع لك وعد بباونتي — وهقولك ليه.
