# تجهيزك قبل الكامب — RVU Camp
By: Ramez Medhat · rv-u.tech

قائمة للاستعداد وليست اختبار قبول. لو نقطة ناقصة، جهّزها أو ناقشها معايا في الانترفيو.

## الأساسيات
- [ ] أقدر أشرح الفرق بين Request وResponse.
- [ ] أعرف وظيفة URL وMethod وHeaders وBody وStatus code.
- [ ] فاهم فكرة الحساب والجلسة والفرق بين الدخول والصلاحيات.
- [ ] جرّبت ألتقط Request باستخدام Burp Suite داخل بيئة تدريب.
- [ ] أعرف أتحرك بين الملفات والمجلدات وأشغّل أمرًا بسيطًا في Terminal.

## الجهاز والاتصال
- [ ] كمبيوتر مناسب، شاحن، وإنترنت ثابت.
- [ ] Burp Suite ومتصفح تجريبي جاهزان.
- [ ] Discord يعمل والصوت واضح.
- [ ] مساحة لحفظ الملاحظات والتسجيلات والملفات التدريبية عند الحاجة.
- [ ] أختبر مشاركة الشاشة قبل أول جلسة.
- [ ] أراجع تعليمات RVU Commerce في مستودعه قبل التثبيت، وأتبع متطلبات النسخة المستخدمة في الكامب.

## الوقت
- [ ] راجع مواعيد الاثنين والخميس ٧:٣٠–١٠:٣٠ مساءً بتوقيت مصر.
- [ ] خصص ٤–٦ ساعات تطبيق أسبوعيًا بجانب السيشنز.
- [ ] احتفظ بوقت لتجميع الأسئلة قبل المتابعة الفردية كل أسبوعين.
- [ ] ١ نوفمبر ٢٠٢٦ هو موعد الإعلان؛ راجع موعد أول سيشن عند إعلان التفاصيل.

## طريقة توثيق المحاولة
اكتب لكل محاولة: كنت متوقع إيه؟ غيّرت إيه؟ حصل إيه فعلًا؟ إيه الدليل؟ إيه اللي مش واضح؟ إيه الخطوة التالية؟

## قبل الانترفيو
جهّز وصفًا مختصرًا لمستواك، مثالًا لمحاولة توقفت فيها، هدفك من الكامب، والوقت المتاح. مش محتاج تحفظ إجابات؛ المطلوب نفهم نقطة البداية.
